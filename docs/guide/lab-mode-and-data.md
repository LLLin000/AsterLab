# 台面执行模式、计时器、照片关联与读数统计

## 1. 走进实验室：切换到「实验」模式

在办公桌写完方案后，带着电脑或平板走到实验台，点击文档右上角的 **「实验」**（或按 `Ctrl + E`）：
- **防误触锁定**：步骤正文、分组定义和孔板布局全部锁住，戴着手套误碰键盘或滑屏也不会改乱原方案；
- **依然开放台面刚需操作**：勾选待办清单、启停计时器、标记异常孔、直接往数据表填数/贴数、给孔位关联显微照片，以及在空白补记区记录突发偏离。

需要修改方案设计时，再点右上角 **「编辑」** 即可随时切回。

---

## 2. 计时器与全流程时间起点（`t0`）

计时器支持 4 种模式，满足几乎所有湿实验节拍：
- **倒计时**：常规孵育、离心、染色、固定；
- **秒表留痕**：记录真实耗时（例如“蓝光照射至水凝胶完全固化，记录实际秒数”）；
- **交替循环**：如“80°C 水浴 5 min ↔ 冰上 10 min，共 3 轮”，自动计算总耗时；
- **时间窗提醒（联动 `t0`）**：
  1. 在关键起点步骤（如「接种完成」或「加药」）标注 `{#t0}`，并在下方时间窗提醒中选择起点 `t0`；
  2. 现场完成该步后点击 **「标记此刻为 t0」**，下游所有 `t0 + 2h`、`t0 + 6h`、`t0 + 24h` 采图或换液提醒会自动换算成精确墙钟时刻并开始倒计时；
  3. 如果打点早了，点击时间条上的 **「重设」** 即可清零重打。

所有运行中的计时器都会汇总在右侧抽屉的「速算计时」与底部状态栏，切去查别的实验也不会错过响铃。

## 3. 显微照片与结果图关联孔位

1. **插入照片**：直接把电脑里的 PNG / JPG 照片拖进文档，或在正文按 `Ctrl+V` 粘贴截图；
2. **关联到孔位**：悬停图片卡片点击 **「关联」**，依次选择：
   - 对应的孔板（或步骤/组别）；
   - 孔位（如 `A1` 或 `A1,A2`）、时间点（如 `6h`）、视野编号（如 `1`）；
   - 照片类型（下拉选择：`观察图` / `原始数据` / `参考图`）。
3. **双向反查**：以后在孔板上点选 `A1` 孔，下方立刻会列出这个孔拍过的所有历史照片；点击任意照片即可放大查看细节。

## 4. 从 Excel / 酶标仪粘贴读数与自动统计

### 4.1 像用 Prism 一样直接粘贴
- **列表视图**：点进数据记录表的任意单元格，直接按 **`Ctrl + V`**，即可把 Excel 里的多行多列数据完整粘入；
- **孔板矩阵视图**：点数据表右上角 **`···` → 切换为孔板矩阵视图**，即可按 12/24/96 孔板排布核对，点进 `A1` 直接 `Ctrl + V` 粘贴酶标仪导出的 8×12 矩阵（自动识别行列头，自动跳过异常孔）。

### 4.2 自动读数汇总
只要数据表关联了孔板或分组，文档底部会自动出现 **「读数自动汇总」** 卡片：
- 自动剔除孔板上标过的 **异常孔**（明确显示 `已剔除 M 异常孔`）；
- 自动识别 **空白孔** 计算本底均值，并给出 **扣空白均值**；
- 清晰区分 **技术复孔数** 与 **独立样本数 `n`**；
- 对 CCK-8 / OD450 活力表自动算相对活力百分比，对 RT-qPCR 含内参基因的 Ct 表自动算 `ΔΔCq` 与相对表达倍数，其他定量表给出清晰的均值 ± 标准差。

## 5. 科研数据导入与多格式导出（CSV / GraphPad Prism / Word `.docx` / PDF）

实验数据既可以原位导入，也能一键输出为下游统计软件和归档所需格式：

- **CSV / TSV / Excel (`.xlsx`) 孔板读数导入**：支持直接解析 96 孔（8×12）与 384 孔（16×24）酶标仪导出表（兼容带仪器表头行的标签矩阵、纯数值矩阵以及带 `Well` 列的长表格式）。
- **Tidy CSV 长表导出（适配 GraphPad Prism / R / Python）**：按规范长表结构（`experiment`, `group`, `role`, `timepoint`, `replicate`, `well`, `sample_id`, `metric`, `value`, `unit` 及扩展列）导出标准 RFC-4180 CSV（可选 UTF-8 BOM，缺失值标注 `NA`），方便直接导入 GraphPad Prism、R `tidyverse` 或 Python `pandas` 进行作图和统计检验。
- **Word `.docx` 实验报告导出**：生成标准 OOXML `.docx` 文档，自动整理实验元信息、分层标题、数据/参数表格、高分辨率 PNG 孔板图与结果附图，以及标准 Word 脚注。
- **A4 PDF 执行单与实测记录单**：支持 Windows / macOS / Linux / Android 跨平台中文字体自适应、可选自定义实验室页眉、`Page X / Y` 页码页脚、表格与孔板跨页防拆保护（避免表格表头或孔板图被页边界截断），并支持在文末附上解析后的 Markdown 批注附录。

## 6. WebDAV 多端同步、科学原图保护与整库备份

如果你需要在实验室台式机、个人笔记本与手机/平板之间同步实验库，AsterLab 内置了专为科研大图像优化的 **WebDAV 同步引擎**（兼容坚果云等标准 WebDAV 服务）：

1. **配置方法**：打开 **设置 → 多端同步**，填入 WebDAV 服务器地址、用户名、应用密码（密码通过系统安全密钥链保存，不会明文写入实验库文件夹）、远端目录与自动同步间隔，可随时点击 **「测试连接」** 或 **「立即同步」**。引擎采用单次清单（`.asterlab/sync-manifest.json`）增量比对，避免高频遍历目录触发网盘限流。
2. **上传端 100% 保留科学原图**：无论是电脑拖入的显微 TIF/PNG，还是手机在实验台现场拍摄的照片，上传端都会**始终无损上传完整原图**到远端内容寻址目录（`assets/originals/<sha256>.<ext>`），同时生成轻量预览图（最大边 1200 px 的 JPEG，存放在 `.asterlab/previews/`）。
3. **移动端按阈值拉取预览，节省流量与空间**：
   - 手机/平板端默认策略为 **「阈值内拉原图（默认 2 MB）」** + **「仅 Wi-Fi 自动拉原图」**：小于阈值的图像直接同步原图，大于阈值的高清显微原图在手机端先自动拉取轻量预览图，需要精细放大核对时再按需点击拉取原图；
   - 可在同步设置中切换为 `仅同步预览图`、`阈值内拉原图（1 / 2 / 5 / 10 MB）` 或 `始终拉原图`，并可随时点击 **「一键释放本地原图缓存」** 清理手机本地缓存（不会删除预览图、电脑端原图或云端原图）。
4. **冲突无损保留与整库 `.zip` 备份**：
   - 多台设备同时离线修改同一份 `.asterml` 时，系统绝不静默覆盖，而是保存 `.sync-conflict-...` 冲突副本，并在同步设置中提供 **保留本地 / 采用远端 / 打开副本** 三选一处理；
   - 储藏室 `pantry.jsonl` 采用追加事件日志合并，天然免冲突；
   - 此外在 **设置 → 文件恢复** 中支持 **「导出整库 .zip 备份」**、**「从 .zip 恢复整库」** 与单文件历史快照回滚，配合崩溃草稿保护确保实验数据安全无忧。
