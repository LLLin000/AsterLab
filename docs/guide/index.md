# 欢迎使用 AsterLab

AsterLab 是一款专为生物与湿实验科研工作者打造的**本地实验记录与设计工作台**。

它把平时散落在 **Word 方案、Excel 孔板图、计算器、手机计时器和纸质实验记录本** 里的内容，收拢到同一份清晰的本地实验文档里——你不需要懂编程或任何复杂语法，点选、拖拽、右键和复制粘贴就能完成从实验设计到结果汇总的全过程。

## 为什么你会喜欢它

- **文件完全留在你自己的电脑里**：所有实验文档与显微照片都以普通文件夹形式保存在本地，不绑架数据、断网也能流畅使用；需要多设备协同时，可在设置中启用 **WebDAV 同步**（支持坚果云等），且上传端始终保留 **100% 无损科学原图**、手机端按大小阈值优先拉取轻量预览图。
- **一份文档贯穿全流程**：顶部放实验分组和孔板图，中间按步骤写操作并放配液计算器与计时器，正文中可随时用 **`@`** 引用储藏室试剂/文档对象、用 **`[^1]`** 添加右侧 **Tufte 边栏批注**，底部直接贴酶标仪读数自动算均值和扣空白。
- **改一处，全篇联动 + Ambient Lab Steward「关联体检」**：在孔板上标记异常孔后，配液计算器、采图槽位与读数统计会自动同步排除；右侧 **「关联体检」** 抽屉会安静检查试剂过期/耗尽风险、汇总可结构化的操作句并召回历史实验与反向链接。
- **写平时的话，就能变出工具**：在步骤里写一句“将 VEGF 稀释至 50 ng/mL，终体积 5 mL”或“37°C 孵育 30 min”，点一下行尾微亮的 `✦`（或按住 `Alt` 悬停），软件会自动帮你算好并一键生成可交互组件。
- **进实验室一键开启防误触，手机端也能单手顺手记录**：切到「实验」模式后，步骤原文与孔板布局自动锁定；移动端提供可自定义的 Obsidian 风格编辑工具栏、滑动手势（`SwipeRow`）与全屏缩放孔板/冻存盒面板，结果可一键导出 **Tidy CSV（GraphPad Prism/R/Python）**、**Word `.docx`** 与 **A4 PDF**。
