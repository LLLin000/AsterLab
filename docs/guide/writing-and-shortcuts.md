# 书写实验笔记、快捷输入与快捷键

你完全可以**全程用鼠标点选**完成所有操作；如果你习惯用键盘快速录入，AsterLab 也支持像 Obsidian / Notion 一样的轻量快捷写法，下面用真实例子一一演示。

---

## 1. 插入步骤与组件（两种方式任选）

- **鼠标点选**：
  - 点击画布顶部悬浮条的 **`+`** 按钮；
  - 或把鼠标移到任意一行的左侧边缘，点击浮现的 **`+`** 图标。
- **键盘 `/` 命令**：
  - 在空白行输入 **`/`**，立刻弹出组件菜单，直接输入中文或英文筛选（如输入 `/孔板`、`/计算`、`/计时`、`/表格`），按回车插入。

---

## 2. 常用快捷输入示例（可选）

下面这些写法全部是**可选的**——不会也没关系，点菜单都能做到：

| 你打出的文字 | 呈现效果 | 适用场景 |
|---|---|---|
| `#@ 细胞接种与铺胶` | 带编号和左侧纵线的 **主步骤** | 划分大的实验阶段 |
| `##@ 配制工作液` | 缩进在主步骤里的 **子步骤** | 细化某一步里的具体操作 |
| `- [ ] 检查培养箱 CO₂ 浓度` | 可直接点击打勾的 **待办核对项** | 实验室防漏步清单 |
| `**全程避光操作**` | **全程避光操作** | 突出关键注意事项 |
| `## 实验目的` | 二级章节标题 | 分隔实验设计与结果讨论 |
| `[[2026-11-18 预实验]]` | 可点击跳转的 **双向实验链接** | 关联上一次预实验或通用 SOP |
| `@VEGF` / `@96孔板` | 行内 **`@` 实体提及胶囊** | 直接引用储藏室试剂/样本、文内组件或实验文档 |
| `观察到轻微沉淀[^1]` | **Tufte 边栏批注 / 脚注**（`Ctrl+Shift+M`） | 在右侧边栏补充注意事项、偏差说明或参考文献 |

> [!TIP]
> 在任意步骤标题后加上 `{#t0}`（例如 `#@ 加药处理 {#t0}`），就能把这个步骤标记为时间起点，后续 6h / 12h / 24h 的时间窗提醒都会以它为基准自动推算时刻。

## 3. `@` 实体提及与 `{@...}` 科学关联

在任意正文段落输入 **`@`**（在中文、空格或标点后直接键入即可），会立即弹出统一的实体补全菜单（手机端为底部单手选择面板）：

1. **储藏室试剂与生物样本**：自动检索你的试剂储藏室（`pantry.jsonl`），列表会附带 **试剂 / 样本** 类别及 **已过期 / 临期 / 已耗尽** 状态提示。选中后插入可点击的试剂胶囊（底层保留可读 Markdown 链接），点击即可跳转到储藏室定位。
2. **本文档内对象**：快速提及当前文档中的 **孔板、配液计算器、参数表、数据表、实验分组与步骤**，便于在文字说明中精准指向特定模块。
3. **跨实验文档**：也可直接选入库内其他实验文档，自动生成 `[[文档路径|标题]]` 双向链接。
4. **科学关系标记 `{@...}`**：在文字或图片后输入 `{@` 可补全孔板或具体孔位（如 `{@plate1:A1}`），悬停可查看关联卡片并在右侧「关联体检」中追踪。

## 4. Tufte `[^1]` 边栏批注（Sidenotes）

写实验注意事项、对照解释或文献出处时，不必把长段说明塞进操作正文里打断阅读节奏：

- **快速插入**：把光标放在需要加注的位置，按下 **`Ctrl + Shift + M`**，或点击悬浮文本工具栏的 **「插入批注 / 脚注」** 图标（也可直接输入 `[^1]` 与 `[^1]: 批注内容`）。
- **桌面端 Tufte 右栏对齐**：在宽屏桌面端开启右侧边栏批注时，所有批注会沿正文右侧边栏与对应上标水平对齐展示；点击批注文字即可直接编辑，按 **`Ctrl/Cmd + Enter`** 或移开焦点自动保存，按 **`Esc`** 取消，悬停右上角可折叠或删除。
- **移动端半高抽屉编辑**：在手机/平板窄屏上，点击上标 `[^1]` 或工具栏批注按钮会在键盘上方弹出半高底部编辑面板，支持折叠、保存与删除，不遮挡操作区。
- **导出保留**：导出 **Word `.docx`** 时会生成标准 Word 脚注；导出 **A4 PDF**（开启批注附录选项）时，所有解析后的 Markdown 批注会自动汇总渲染在文末 **「附录：实验批注与参考文献」** 中。

## 5. 移动端（手机 / 平板）工具栏与手势操作

AsterLab 针对手机和平板端提供接近 Obsidian Mobile 的流畅单手操作体验：

- **可自定义的键盘上方编辑工具栏**：编辑文档时，键盘上方会显示可横向滑动的快捷工具条，包含科学动作（`@` 提及、`/` 插组件、`[^1]` 批注、`✨` 转结构、现场拍照、计时器、加步骤）、排版结构（撤销/重做、标题、加粗、待办、无序列表、缩进/退格、块上移/下移、折叠）与光标微调/收起键盘。
- **自由排序与显隐**：打开 **设置 → 外观 → 自定义移动端编辑工具栏**，可以开关任意按钮的显示状态、上下调整排序或一键 **「恢复默认工具栏」**（设置保存在 `.asterlab/mobile_toolbar.json`）。
- **常用手势（含触觉反馈）**：
  - **文件树滑动操作（`SwipeRow`）**：在左侧实验库抽屉中，条目 **向右滑** 可置顶/取消置顶，**向左滑** 可创建副本或删除；
  - **实验模式快捷滑动**：在「实验」模式下，向右/左滑动待办项可快速勾选完成，滑动步骤横幅可快速调出计时；
  - **长按底部菜单**：在窄屏或移动端长按文件或组件，会弹出高度 ≥ 48dp、拇指易触达的底部操作面板；
  - **顶部下拉快捷动作**：在画布顶部下拉可触发快捷动作（默认打开命令面板，可在 **设置 → 外观 → 顶部下拉快捷动作** 中改为新建实验、速算与计时或打开实验库）；
  - **移动端日历手势**：日程视图在手机端自动切换为 **3 日 / 单日议程卡片** 与支持左右滑动的 **7 天横向日期条**。

## 6. 全部快捷键速查表

| 快捷键 | 做什么 |
|---|---|
| `Ctrl + K` | **快速跳转**：输入实验名瞬间切换，或搜索任意功能 |
| `Ctrl + Shift + F` | **全库全文搜索**：在所有历史实验里搜试剂、批号或现象 |
| `Ctrl + E` | 在 **「编辑」** 与 **「实验（防误触）」** 模式间一键切换 |
| `Ctrl + F` | 在当前实验文档内查找文字 |
| `Ctrl + Shift + M` | 在当前光标处插入 **Tufte 批注 / 脚注**（`[^1]`） |
| `Ctrl + B` / `Ctrl + I` | 加粗 / 斜体 |
| `Alt + 悬停` / `Alt + Enter` | 识别当前操作句，预览并一键转为计算器、计时器或孔板 |
| `Ctrl + V` | 在数据表/孔板矩阵中直接粘贴 Excel 或酶标仪多行数据；在正文中直接粘贴截图 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + \` | 展开或收起左侧文件栏 |
| `F2` / `Delete` | 在左侧文件树重命名 / 删除选中的实验或文件夹 |
