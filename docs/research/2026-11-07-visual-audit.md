# AsterLab 视觉审查:设计工作流与执行驾驶舱

- 日期:2026-11-07
- 范围:Western blot 11 步设计页、执行页、Protocol/记录/工具页
- 视口:1440×1000、390×844
- 状态:本地浏览器实测;不是用户测试

## 结论

修完后,设计页和执行页在 1440 与 390 下都没有横向溢出。设计页的 11 步在桌面是 6+5 两行流程图,在手机改为横向步骤条;执行页在桌面是三步模块并排,手机单列。

## 发现并修掉的问题

| 问题 | 证据 | 处理 |
|---|---|---|
| 流程节点图标变成黑色实心烧瓶 | 1440 设计页 | SVG 补 `fill=none`、`stroke=currentColor`、描边宽度 |
| 所有步骤共用烧瓶图标 | 1440 设计页 | 按步骤名映射 reader/incubator/plate/flask/pipette |
| 摘要标题和“2 组”贴在一起 | 390/1440 设计页 | 摘要标题加右间距 |
| 手机设计页流程图被缩到不可读 | 390 设计页 | ≤700px 隐藏 SVG 画布,显示可横向滚动的步骤条 |
| 执行页三个模块上下堆叠,留白巨大 | 1440 执行页 | 覆盖 `.page-card` 的 `grid-column:span 12`,恢复三列 |
| 执行表单 textarea 和状态字段重叠 | 1440 执行页 | 表单改为独立两列网格,实际内容占满一行 |
| 手机执行页顶部状态/开发按钮压住标题 | 390 执行页 | 手机隐藏状态胶囊和开发入口 |
| 设计页只读表格仍带 ↑↓× 操作 | 390 设计页 | 只读表格隐藏 card actions |
| Protocol 版本下拉显示完整时间戳并溢出 | 1440 Protocol | 只显示日期;限制下拉宽度 |

## 最终画面检查

- 设计页 1440:11 个节点全部可见;节点图标为线性图标;节点下方显示材料/仪器数量;摘要、按钮、画布、详情没有横向溢出。
- 设计页 390:流程图替换为 11 个横向步骤条;点步骤更新详情;材料表不再有编辑操作。
- 执行页 1440:当前步骤、三个模块、记录表单、本步记录按顺序出现;三模块并排;表单不重叠。
- 执行页 390:步骤条可横向滚动;三个模块单列;表单单列;无横向溢出。
- 完成态:11/11 全部完成后隐藏表单,显示“本次运行已完成”。
- 阻塞检查:失败时停留原步骤,事件记为 blocked。

## 仍未解决

- 设计页流程节点只显示材料/仪器数量,不显示具体仪器名称。
- Protocol 页的材料/设备来自 Protocol 参数,而设计 View 里的材料/仪器表不会被 Protocol 页读取;两处仍可能看起来不一致。
- 记录页里同一设计的多个 Run 标题相同,只能靠下拉顺序区分。
- 尚未做真实用户走查、对比度测量或键盘全流程测试。
