# Plan → Session → Results:双场景走查

- 日期:2026-11-07
- 状态:本地浏览器走查;不是用户测试
- 场景 A:L929 + GelMA/ZnO 浸提液,CCK-8 与 LIVE/DEAD,D1/D3/D7
- 场景 B:Western blot 11 步

## 结论

当前已经有 Plan / Session / Results 三个内部状态,但没有新增第五个主标签:

- **Plan**:设计摘要按检测分行,显示每组时间点和时间点关系;编辑器可编辑全部检测,不再只处理 `assays[0]`。
- **Session**:Run 北京时间点筛选任务;默认落到未完成时间点;确认按任务进行;阻塞检查门禁;冻结资源。
- **Results**:Run 内部标签,展示所有执行事件、读数/测量数量、检查数量和“已完成但无读数”的任务。

## 场景 A:L929 多检测跨天

### 已走通

1. Design 摘要显示:
   - CCK-8 · D1/D3/D7 · 同一实体样本重复 · OD450 · Protocol
   - LIVE/DEAD · D1/D3/D7 · 每时间点独立样本 · 图像终点 · Protocol
2. 编辑器显示 2 个检测卡,可分别编辑名称、终点、方法、单位、时间点、时间点关系、对照。
3. Run 显示 D1 / D3 / D7 时间点条;每个时间点 3 个任务:CCK-8 read、Stain LIVE/DEAD、Image。
4. 当前任务在 D1 内前进;D1 全部完成后才进入 D3,不再从 CCK-8 D1 直接跳到 CCK-8 D3。
5. Run 顶部 project/design 上下文会同步到当前 Run,不再出现打开 L929 Run 却显示 Western blot 项目。

### 仍缺

- L929 演示项目没有绑定 View,Session 的三块材料/仪器/检查显示“未绑定”;Plan 摘要能看,但执行页没有可核对材料。
- 设计只有组别和时间点,没有逐孔 Sample ID;`PlannedTask.target` 仍是 `Unresolved`。
- 没有实验前“需要准备什么”的汇总;资源需求仍依赖后续 View/Protocol。
- 结果只能查看,不能批量粘贴/导入 OD 或 Cq。

## 场景 B:Western blot

### 已走通

1. 11 个任务按步骤显示;默认停在未完成步骤。
2. 阻塞检查未记录时确认按钮禁用;记录通过后进入下一步。
3. 完成事件自动写时间;不要求备注/操作人。
4. Run 创建时锁定当前 View id,并把材料/仪器/检查表冻结到 `execution_resources`。
5. 完成态 11/11 只读;顶部显示“全部任务已完成”。
6. Results 标签列出所有事件;可看到完成但无读数的任务。

### 仍缺

- ECL 成像没有图片关联入口;Results 只能显示已有事件。
- 操作完成与结果完整仍未由步骤级“必需结果”契约驱动;当前用“无读数”提示,不判断是否必需。
- 结果录入仍是只读汇总。
