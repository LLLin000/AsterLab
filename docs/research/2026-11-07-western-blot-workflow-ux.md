# Western blot 工作流 UX 试验

- 日期:2026-11-07
- 状态:在现有 Workflow 上做的真实数据试验;不是用户测试结论,也不是最终 UI 规格。
- 目的:用比 qPCR 更复杂、需要更多材料与仪器的实验,检查“设计简单但要点都在”和“执行时一眼知道下一步”是否成立。

## 为什么换实验

qPCR 只有少量步骤,不能暴露真实问题。Western blot 被选作第一个压力案例,因为它同时包含:

- 11 个操作步骤:裂解、BCA、变性、SDS-PAGE、转膜、封闭、一抗、洗膜、二抗、洗膜、ECL/成像。
- 多类材料:裂解液、BCA 试剂、凝胶、膜、抗体、ECL。
- 多类仪器:离心机、酶标仪、金属浴、电泳仪、转膜槽、摇床、成像仪。
- 多类检查:membrane 无气泡、marker 分离、loading control 均一、条带未饱和。
- 组别 × 时间点 × 检测的设计关系。

## 结论

当前最清楚的页面结构不是“把所有 SOP 字段摊在画布上”,而是三层:

1. **摘要层**:设计名、组数、时间点、检测/终点、Protocol、待确认数。
2. **流程层**:11 个步骤按操作顺序排布;超过 6 个时自动换行,而不是缩到看不清。
3. **步骤层**:只显示当前步骤的四个模块:
   - 做什么:一句话 Execution brief。
   - 用什么:材料与试剂。
   - 怎么做:仪器与程序(关键设置)。
   - 做到什么程度:检查与接受。

设计时只需要编辑第一层和步骤层的关键参数;完整配方、仪器程序、检查项属于 Protocol/步骤详情,不应在摘要里展开。

## 已在界面上验证

### 设计页

- 11 个节点按 6 + 5 两行排布,节点文字保持可读。
- 点击“一抗孵育”后,详情按顺序显示:
  - 一抗:p-AKT(按 Protocol 稀释)
  - 抗体稀释液:TBST + BSA
  - 摇床:4 °C · overnight
  - 检查:抗体覆盖膜面 / 无干膜
- 材料、仪器、检查现在是只读展示表,不再显示“添加列/删除行/保存表格”的编辑噪声。
- 摘要保持一行,不重复步骤正文。

### 仍然暴露的问题

- 材料/仪器目前是 View 组件内容,不是 typed binding;它们能显示,但不能被 Agent 或工具按类型读取。
- 节点上还没有材料/仪器数量或仪器名称的徽标,必须点开才看到。
- 工具中心还不能从当前步骤直接发起“离心/读板/成像”等动作。
- Run 页还没有切换成“当前步骤单卡片”模式;它仍复用 View 的详情。
- 表格只读展示只覆盖带 `materials/instruments/checks` preset 的表;其他表仍是编辑器。

## 下一步 UX 规格

### 设计页

- 顶部摘要固定四项:设计意图、组别/时间点、检测/终点、待确认。
- 流程节点只显示:步骤名 + 一个关键参数 + 材料/仪器状态点;不显示全部参数。
- 步骤详情按四个模块排序;每个模块最多 4 行,超出折叠。
- “编辑本次安排”只改设计特有字段:组、n、时间点、终点;不改 Protocol 配方。

### 执行页

执行页应是单步驾驶舱,不是缩小版设计页:

- 当前步骤大标题 + “为什么现在做这一步”。
- 一个主要操作卡:材料、仪器、设置、目标样本。
- 一个检查卡:完成条件、阻塞项、异常记录。
- 一个“记录并进入下一步”动作;历史事件默认折叠。
- 下一步预览只显示名称和预计时长,不提前展开。

### 工具/仪器

- 每个步骤有稳定的 `materials[]`、`instruments[]`、`tools[]` 引用。
- 工具中心按步骤推荐工具,不要求用户从仪器百科里找。
- 仪器设置来自 Protocol 版本;本次偏离必须显式记录为 deviation,不能静默覆盖。

## 验收

- 11 步 Western blot 在 1440 宽度下全部可见、文字可读。
- 任意步骤点开后,材料、仪器、检查三项无需滚动即可看到第一部分。
- 摘要不重复步骤正文;步骤卡片不重复 Protocol 全文。
- 执行页一次只强调一个当前步骤,并给出可执行的下一步。
- Agent 能读取同一步骤的 typed 材料/仪器引用,而不是解析表格文本。

## 证据

本轮只对本地 demo 数据做了界面核对;没有真实 Western blot 执行数据,也没有用户走查。正式规格需在真实实验室流程中复核。
