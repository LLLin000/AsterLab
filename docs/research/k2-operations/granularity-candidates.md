# 粒度候选审查(初稿)

- 日期:2026-11-05
- 状态:研究审查,不是最终模块清单;所有记录仍为 `research_draft`
- 标准:[record-standard §1.1–1.3](../record-standard.md#11-粒度判定最小可审计科学操作)
- 方法:从现有操作记录中选 18 个候选,逐项回答:独立目的、稳定边界、独立确认、有意义复用、是否继续拆/降级。

> 说明:这是初轮审查规模,不是 AsterLab 的长期模块上限。**不要因为本表存在就批量生成 JSON。**
>
> 复审后的最终裁决见 [granularity-freeze.md](granularity-freeze.md);有争议的条目以 freeze 的裁决为准。

## 1. 结论分组

### A. 适合作为 Atomic Operation

| 候选 | 独立目的 | 稳定边界 | 独立确认 | 复用 | 判断 |
|---|---|---|---|---|---|
| 液体转移 | 移动定量液体 | 来源/目标/体积/吸头 | 实际体积可记录 | 接种、加药、洗涤、分样 | 原子 |
| 取样/分样 | 从父样本取出一部分 | 父子样本、体积、容器 | 父子 ID/体积可记录 | 培养上清、核酸、蛋白 | 原子 |
| 孵育/培养保持 | 在受控环境下保持 | 时间锚点、温度、气氛、容器 | 起止/偏差可记录 | 细胞、微生物、染色 | 原子 |
| 洗涤 | 交换液体、去除未结合物 | 样本/废液/缓冲液 | 循环/残留/损失可记录 | 细胞、ELISA、生物膜 | 原子,但需 loss policy |
| 离心 | 分离相 | 转子/RCF/时间/容器 | 上清/沉淀可记录 | 细胞、核酸、蛋白 | 原子 |
| 吸光度读取 | 记录原始光信号 | 板/波长/空白/仪器 | 原始值/元数据 | CCK-8、ELISA、CV | 原子 |
| 荧光成像 | 记录图像 | 通道/物镜/位置/曝光 | 图像/元数据 | 活死、IF、划痕 | 原子 |
| 划线接种 | 在固体表面形成空间分布 | 来源培养物/培养基/接种量 | 可见生长/污染可记录 | 微生物纯化 | 原子,不拆每一笔 |
| 涂布接种 | 在表面均匀分布 | 来源/体积/涂布器/培养基 | 菌落/污染可记录 | 微生物计数 | 原子,不拆每次移动 |
| 菌落计数 | 对已培养平板计数 | 平板/稀释/计数窗口 | 计数/图像可记录 | CFU、克隆计数 | 原子读数 |
| 细胞计数/活力 | 测悬液浓度/活力 | 样本/方法/稀释 | 计数/活率可记录 | 接种、传代、冻存 | 原子 |
| 核酸/蛋白定量 | 测浓度/纯度 | 样本/方法/blank | 值/方法可记录 | qPCR、WB | 原子读数 |

### B. 通常应作为 Composite Block

| 候选 | 拆成什么 | 不继续拆的原因 |
|---|---|---|
| 细胞传代 | 洗涤/解离/离心/计数/接种/孵育 | 多阶段、谱系更新 |
| 连续稀释 | 多次液体转移 | 单次转移已有模块;组合决定梯度 |
| 静态生物膜培养 | 接种+孵育(+换液) | 多阶段,产生附着/浮游 fractions |
| 离心后取上清 | 离心 + 取样/转移 | 分离与取液是两个意图 |
| 染色流程 | 洗涤+染色+洗涤(+固定/通透) | 方法特定参数和时序 |
| 固定/通透/封闭 | 多个液体交换/孵育步骤 | 每一步有独立条件,组合才是流程 |

### C. 应作为 Method Template

| 候选 | 原因 |
|---|---|
| CCK-8 | 含接种、处理、孵育、加试剂、读板、计算;多种变体 |
| ELISA | 包被/封闭/样本/检测/底物/读板;方法变体多 |
| Western blot | 裂解/定量/电泳/转膜/封闭/抗体/检测 |
| qPCR | 提取/QC/RT/扩增/分析;MIQE 控制 |
| 流式 panel | 样本制备/染色/采集/设门;panel 特定 |
| 免疫荧光 | 固定/通透/封闭/抗体/成像;抗体/通道特定 |
| 生物膜 CV | 洗涤/染色/溶解/读板;总生物量 |
| 生物膜 CFU | 洗涤/分散/稀释/铺板/培养/计数;活菌 |

### D. Assay Model, not module

- 生物膜形成
- 细胞活力
- 蛋白表达
- 迁移/侵袭
- 抗菌敏感性

### E. Custom Step 候选

- 新染色/新材料处理,没有稳定模块;
- 需要研究者判断“是否继续”的中间步骤;
- 设备/操作姿势类动作(如“轻敲”“旋转混匀”),除非有独立科学意图和可验证边界。

## 2. 逐项五问摘要

| 候选 | 为什么独立? | 继续拆? | 边界? | 复用? | 契约缺口 |
|---|---|---|---|---|---|
| 液体转移 | 一次物质转移 | 不拆吸/排液 | 是 | 是 | 条件模式执行 |
| 取样 | 产生父子样本 | 不拆吸头动作 | 是 | 是 | 数量守恒 |
| 孵育 | 一次受控保持 | 不拆升温/稳定 | 是 | 是 | 实际状态变化 |
| 洗涤 | 一次液体交换 | 不拆每孔 | 是 | 是 | 损失量 |
| 离心 | 一次分离 | 不拆加速/减速 | 是 | 是 | 转子/RCF |
| 读取 | 一次测量 | 不拆采光/读值 | 是 | 是 | 单位/线性 |
| 划线 | 一次表面分布 | 不拆每一笔 | 是 | 是 | 空间结果 |
| 涂布 | 一次表面接种 | 不拆每次移动 | 是 | 是 | 均匀性 |
| 细胞传代 | 多阶段 | 拆 | 组合 | 是 | 谱系 |
| 生物膜 CV | 方法终点 | 拆 | 方法 | 是 | 损失/对照 |
| 生物膜 CFU | 方法终点 | 拆 | 方法 | 是 | 分散效率 |

## 3. 审查结论

- 初轮候选足够覆盖移液、分离、培养、接种、测量五类语义。
- 划线/涂布是原子操作,但不要拆到每一笔/每次移动。
- 离心后取上清必须与离心分开。
- 细胞传代、生物膜培养、CV/CFU 不是原子操作。
- 没有稳定边界的动作应进 Custom Step,不要强行加模块。
- 本轮不生成新 JSON;先由第二人复核候选边界。
