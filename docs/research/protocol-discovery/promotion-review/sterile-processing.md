## 4. 六维对照：过滤 vs 高压（显式拒绝合并）

| 维度 | SterileFiltration（候选） | Autoclave（候选） | 不合并理由 |
|---|---|---|---|
| 目的 | 尺寸截留：让溶解组分通过，微生物截留在膜上；**热敏体系首选**（S1 灭菌节） | 湿热杀灭：已配制水溶液在容器内接受高温高压循环；**耐热体系适用** | 机理相反（去除 vs 杀灭）；适用性互补而非互换：DMEM 热敏走过滤，PBS/LB 耐热走高压 |
| 端口 | 待滤液 + 滤器/驱动 + 无菌接收容器 → 无菌滤液 + 废滤器（滤器为耗材，有方向性） | 待灭菌液 + 可高压容器（含盖/通气）→ 已灭菌溶液（同一容器内）+ 冷却/储存约束 | 耗材流向不同（过滤新增废滤器谱系；高压容器不变）；接收容器无菌前置假设不同 |
| 样本/材料 effect | 截留 effect：微生物/颗粒 loss 在膜上；滤液组分原则上透过（但吸附/截留定量 UNKNOWN） | 杀灭 effect：微生物失活在原容器内；热敏组分同时降解（S1 添加物必须后加即证据） | effect 不兼容：过滤无热降解，高压有热降解；把一者参数化为另一者分支即 G2 失败 |
| 完成/验证 | 操作完成 = 液体通过 + 无菌收集；无菌保证 = 方法假设（完整性测试无证据） | 操作完成 = 循环执行 + 冷却 + 盖紧；无菌保证 = 方法假设（BI/柜确认无证据） | 两者的"保证"缺口类型不同（膜完整性 vs 柜/装载确认）；验证不得立为通用步骤（题设规则） |
| 仪器要求 | 过滤驱动能力（正压/真空/注射器）+ 膜 + 无菌接收链 | 高压蒸汽 chamber 能力 + 通气/装载 + 冷却链 | 能力类别无交集；具体型号/压力/程序一律 UNKNOWN，不得互借规格 |
| 差异成本 | 统一需分支：正压 vs 真空（驱动）、0.2 vs 0.22（字面）、膜/面积/压力/通量（全 UNKNOWN）= 至少 2 个显式分支 | 统一需分支：115 °C/10 min vs 未写值（循环）、片剂 vs 散盐 vs LB（含氮体系）、Duran vs 松盖锡纸（装载）、冷却/储存 = 整套分支重写 | 任一候选统一即"分支 = 新操作"，G4 均不过；且两候选之间分支零复用，合并成本更高 |

## 5. 与溶液/培养基配制的边界（配制链不建模块）

配制链各步归属（沿用 B08 §9，不变）：

| 配制链步骤 | 归属 | 与本复审的关系 |
|---|---|---|
| 称量（粉末/盐克级；片剂计数） | ToolAction（质量/计数读数）+ method-local；不建模块 | 前置 Dixon，与灭菌机理无关；天平规格 UNKNOWN |
| 溶解/混匀（粉末搅拌不加热/不过混；片剂崩解；磁力 ~3 min；rinsing 手法） | method-local（独立候选）；不并入转移/洗涤；不晋升 | 前置条件：未溶清即过滤堵塞/高压前浓度不均；但机理（搅拌 vs 崩解）G2 不过 |
| pH 调节（S1/S2 offset 滴定 0.2–0.3 + 回升；S4 双目标 7.2/7.4；S3 验收窗 7.3–7.5） | method-local；三种 pH 语义互不合并；不晋升 | 顺序约束（调后定容/过滤；S2 调后密闭至过滤），不是灭菌参数 |
| 定容/加水/转瓶/分装进无菌容器 | `op.liquid_transfer` 参数化复用（已有共享） | 灭菌前后的转移语境；本复审不新增 |
| 储存（S1 标签温度；S2 4 °C 暗 12 个月；S4 RT or 4 °C 期限 UNKNOWN） | 方法约束，非操作；禁并入 `op.incubation`（B08 §8 G-7） | 灭菌后独立保持窗；稳定性不断言 |
| 灭菌后添加（碳酸氢钠/L-谷氨酰胺/抗生素/血清；冷至室温才加） | 方法模板内添加规则 + 方法约束 | 证明高压与过滤是**方法内互斥分支**，不是同一操作的参数 |

组合关系（非模块）：

```text
Method Template（P-DMEM / P-PBS-Tablet / P-PBS-Salts / P-LB）
 = op.liquid_transfer（加水/定容/转瓶/分装）
 + method-local 溶解/混匀 + method-local pH（按方法取舍）
 + [ SterileFiltration │ Autoclave ]（二选一分支，按热敏性路由）
 + 方法储存约束 + 方法添加规则
```

因此不存在 "media prep / solution prep" 公共模块：它的成员分属 ToolAction / 已有共享 / method-local / 本复审两候选；整体是方法模板的固定顺序，不是原子操作（record-standard §1.2；granularity-freeze §5.2）。
