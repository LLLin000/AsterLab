# 更广的 UI 参考:数据面板、表格、表单与定位

- 日期:2026-11-08
- 来源:X 公开搜索与帖子;不是完整行业综述
- 目的:避免只看一个账号,补充数据表格、表单、仪表盘和层级定位的做法

## 读到的主要方向

### 1. 表格与实时数据

公开帖中反复出现两点:

- **数字用等宽数字**:`font-variant-numeric: tabular-nums`。默认数字宽度不一致,更新时会抖动,列也对不齐。
- **不要伪造变化幅度**:仪表盘从 1 变成 0 时,不标红色 `−100%`,用灰色小字说明“之前 1”;坐标轴取整数刻度。

AsterLab 已对所有只读表格和 Run 材料表启用 tabular numbers。当前没有趋势图,暂不引入“变化幅度”组件。

### 2. 嵌套圆角

- 经验公式:**内圆角 = 外圆角 − 间距**,尽量共用圆心。
- 连续曲率(超椭圆)能让圆角与直边衔接更顺,但浏览器支持仍需 fallback。
- 大面板、侧边栏可以保持直角;卡片和小控件再加 2–4px 圆角。

AsterLab 当前卡片 10px、内部控件 6px。没有强行套超椭圆,因为表格和实验控件的可读性优先。

### 3. 表单载体

- 短表单、不需要参照页面:Dialog。
- 长表单、需要对照页面或横向空间:Drawer。
- 任务本身就是主流程:完整页面。
- 误关后能否恢复草稿,比动画更重要。

AsterLab 的多检测设计编辑器已改为右侧 Drawer;草稿恢复仍未做。

### 4. 用户始终知道“我在哪”

复杂产品需要面包屑、当前步骤、状态栏和下一步。地图类产品的“我在哪里”原则同样适用于实验执行。

AsterLab 已有项目/设计/View 面包屑、Run 步骤条、`当前任务 x/y`、下一步名称。

### 5. 浮层选择

来自 Kubai 009 的规则:

- Tooltip 只补文字。
- Popover 承载操作。
- Popconfirm 做单条不可逆确认。
- Dialog 处理高影响、批量或短表单。
- Drawer 处理长表单。
- 完整页面处理主任务。

AsterLab 的 Proposal 和组件库是 Popover;设计编辑器是 Drawer。

## 已应用

- 只读表格和 Run 材料数字启用 tabular numbers。
- 长设计表单改为 Drawer。
- 两列组件布局保留 8:4 孔板/计算器比例。
- 组件浮层支持外部点击、`×`、Esc。
- 标题/正文启用 `text-wrap: balance/pretty`。

## 不照搬

- 没有引入复杂仪表盘图表或多层卡片;当前核心是计划、执行和结果。
- 没有全面使用液态玻璃;实验室界面需要稳定对比度。
- 没有为了“好看”增加装饰性图标、徽标或动画。
