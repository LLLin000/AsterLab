# 从 Kubai (@Kubai087) 的 UI 技巧到 AsterLab

- 日期:2026-11-08
- 来源:X 账号 [@Kubai087](https://x.com/Kubai087),公开帖与公开镜像
- 状态:设计借鉴记录,不是对原作者方法的完整复刻

## 读到的四条原则

1. **浮层要分层**
   工具提示、popover、确认气泡、抽屉、对话框和整页不是同一种东西。浮层必须能明确关闭,并让用户知道当前在哪一层。

2. **连续性不是交叉淡化**
   界面状态变化时,元素要从一个位置/形状/注意力焦点迁移到另一个,而不是突然替换。下拉、抽屉、手风琴、标题切换都属于这一类。

3. **材质靠小配方**
   拟物感通常来自描边、投影、极淡背景渐变和内发光高光,而不是堆叠重阴影或高饱和渐变。

4. **动画有分工**
   - ease-out:浮层、菜单、toast 入场
   - strong ease-out:点击后立即落位的小元素
   - ease-in:关闭、退场
   - ease-in-out:原地换位的指示条、滚动
   - overshoot:只用于小元素

## 更具体的选取规则

Kubai 的 009 帖把浮层按用途拆开:

- Tooltip:只补充文字,不承载操作。
- Popover:需要点击操作。
- Popconfirm:单个项目、不可撤销,就地确认。
- Dialog:影响大、批量、必须打断,或短表单。
- Drawer:长表单、需要对照页面、需要横向空间;不用于确认。
- Full page:任务本身就是主流程,或需要可分享 URL。

长表单还有一个容易漏的点:误关后能否恢复草稿。AsterLab 的设计编辑器因此改成右侧 Drawer,保留设计页上下文,并有明确取消。

动画按角色分工:浮层入场 ease-out,离场 ease-in,原地移动 ease-in-out;小元素才用 overshoot;还要尊重 `prefers-reduced-motion`。

## 应用到 AsterLab

| 原则 | AsterLab 调整 |
|---|---|
| 浮层分层 | `+ 组件`、Inbox、Proposal 保持独立浮层;Proposal 支持 `×`、点外部、Esc 关闭 |
| 连续性 | 卡片选中态、步骤 chip、浮层入场增加短过渡;保留 reduced-motion |
| 材质 | 组件卡片加内高光、轻投影、hover 描边;深浅主题分开处理 |
| 尺寸不统一 | 孔板约 2/3、计算器约 1/3;普通表格两列;说明整行 |
| 动画节奏 | 浮层使用短 ease-out;关闭动作不拖沓 |
| 长表单 | 设计编辑器改为右侧 Drawer,不把几十个字段塞进小浮窗 |

## 不照搬的部分

- 没有引入动态图标或复杂材质动画。AsterLab 是实验室工具,过度动效会干扰读数与执行。
- 没有把所有卡片做成同一种玻璃/拟物样式。组件的用途、尺寸和信息密度优先于统一装饰。
- 没有为装饰图生成夜景版;当前界面没有需要昼夜切换的主视觉。
