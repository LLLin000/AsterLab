## 一、纸面完整实验设计（业务真相源）

### 1.1 因子、分组与 12 孔板布局
- **研究体系**：DMEM 高糖 + 10% FBS + `10 ng/mL VEGF`（全组统一添加）
- **单一自变量**：GelMA 浓度（`3%`、`5%`、`7%` w/v），固定溶剂为 `0.25% (w/v) LAP` 溶液
- **容器与复孔**：1 块 12 孔板（3 行 × 4 列），使用 9 孔（每组 3 个技术复孔），第 4 列留空或加无菌 PBS 防边缘蒸发：

| 行 \ 列 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **A** | `3% GelMA` (`HUVEC-3%-1`) | `3% GelMA` (`HUVEC-3%-2`) | `3% GelMA` (`HUVEC-3%-3`) | 空白 / PBS |
| **B** | `5% GelMA` (`HUVEC-5%-1`) | `5% GelMA` (`HUVEC-5%-2`) | `5% GelMA` (`HUVEC-5%-3`) | 空白 / PBS |
| **C** | `7% GelMA` (`HUVEC-7%-1`) | `7% GelMA` (`HUVEC-7%-2`) | `7% GelMA` (`HUVEC-7%-3`) | 空白 / PBS |

### 1.2 配液与细胞计算清单（含合理余量）
1. **GelMA 前驱液**（每组净需 `3 × 0.5 mL = 1.5 mL`，按黏稠液体 +1 孔余量配 **`2.0 mL/组`**）：
   - `3% GelMA`：`60 mg` GelMA + `2.0 mL` `0.25% LAP`
   - `5% GelMA`：`100 mg` GelMA + `2.0 mL` `0.25% LAP`
   - `7% GelMA`：`140 mg` GelMA + `2.0 mL` `0.25% LAP`
2. **浸泡平衡完全培养基**（第 3 步，不加 VEGF）：`9 × 1.0 mL = 9.0 mL`（配 `10.0 mL` DMEM 高糖 + 10% FBS）。
3. **HUVEC 细胞悬液 + VEGF**（第 4 步，净需 `9 × 0.5 mL = 4.5 mL`，按 10 孔余量配 **`5.0 mL`**）：
   - 目标：`1×10⁵ cells/孔` @ `0.5 mL/孔` → 悬液密度 **`2×10⁵ cells/mL`**，细胞总数 **`1.0×10⁶ cells`**；
   - `VEGF`（工作浓度 `10 ng/mL`）：按 `10 µg/mL` 母液计，加入 `5.0 µL` 母液至 `5.0 mL` 悬液中（`1:1000`）。

### 1.3 标准流程与时间预算（含可并行空窗）

| 步骤 | 动作与关键参数 | 时间属性 | 估算耗时 | Run 时必须记录的客观事实 |
|---|---|---|---|---|
| **01** | `(80 °C 水浴 5 min → 冰上 10 min) × 3`；视气泡决定是否 `2000 rpm` 离心脱泡 | 短循环 + 条件操作 | `45 min`（+0–5 min） | 3 轮各自完成时间；各浓度是否执行离心或“无气泡按规则跳过” |
| **02** | 铺胶 `0.5 mL/孔` 铺匀；`405 nm` 紫外照射至固化（参考 `~120 s`） | 连续操作 + 判定型计时 | `~10–15 min` | 铺匀确认；**实际照射时长（s）**（各浓度可分别记录） |
| **03** | 加 `1.0 mL/孔` 完全培养基；`4 °C` 浸泡 **`≥ 2 h`** | 加液 `3 min` + **Wait `≥ 2 h`** | `≥ 123 min`（**可穿插其他实验**） | 放入 `4 °C` 时刻、取出时刻、实际浸泡总时长 |
| **04** | 复温并吸去旧液；接种 `0.5 mL/孔` HUVEC 悬液（含 VEGF） | 连续操作（建立 **$t_0$**） | `~20 min` | 接种浓度与 VEGF 确认；**放回培养箱绝对时间戳 $t_0$** |
| **05a** | `t0 + 6 h` 明场观察：9 孔 × 6 视野 | Wait `6 h` + 采集 `~18 min` | `~18 min` | **54 张显微图像**（绑定 `Well × 6h × FOV 1..6`）+ 实际拍摄时刻 |
| **05b** | `t0 + 12 h` 明场观察：9 孔 × 6 视野 | Wait `6 h` + 采集 `~18 min` | `~18 min` | **54 张显微图像**（绑定 `Well × 12h × FOV 1..6`）+ 实际拍摄时刻 |
| **05c** | `t0 + 24 h` 明场观察：9 孔 × 6 视野 | Wait `12 h` + 采集 `~18 min` | `~18 min` | **54 张显微图像**（绑定 `Well × 24h × FOV 1..6`）+ 实际拍摄时刻 |

- **全流程时间画像**：总跨度 **~27.5 小时**；净占人手操作时间 **~2.5 小时**；首日 `Step 3 (≥2h)` 及 `6h / 12h / 24h` 之间均为空闲可并行窗口。
- **后处理延迟指标**：管腔总长度、节点数、网格数等定量指标标记为 `post_run_deferred`，不阻塞 Run 推进，图像分析后按 `Well × Timepoint` 回挂。

## 二、用当前 AsterLab 映射后的 8 个核心缺口

在编写 `huvec-tube-formation.asterml` 时，凡是“硬塞进去才合法”或“目前根本写不出来”的地方，直接暴露了底层与 UI 的改造清单：

1. **单位子集缺失（`spec/units.json`）**：无法原生表达 `3% / 5% / 7% (w/v)`、`2×10⁵ cells/mL`、`2000 rpm`，只能人工换算成 `30 mg/mL` 或退回文本。
2. **计算器非通用（`modules.json`）**：`dilution@1` 只能算 VEGF，`rna_reagent_usage@1` 绑死在 RNA。缺少“选定孔板 9 孔 × 单孔用量 × 余量 → 自动输出 GelMA 称重 & 细胞总数 & 配液体积”的通用配液/细胞接种计算器。
3. **12 孔板前端不可交互（`module-catalog-v1.md` §1.1）**：后端 `plate@1` 支持 `6/12/24/48/96/384`，但 Design UI 只有 96 孔有交互式分配器。
4. **流程无循环与条件跳过原语（`step@2/3`）**：3 轮冷热循环被迫拆成 3 条 `tasks` 文本；“无气泡可跳过离心”无法与“异常偏差”区分。
5. **时间模型缺少“耗时预算 + 实时计时器 + 运行期锚点”**：
   - Design 算不出“净人手时间 vs 空窗可并行时间”；
   - Run 没有绑定步骤的计时器组件（循环倒计时、405nm 正计时、跨页常驻的 `4°C ≥2h` 与 `t0 + 6/12/24h` 后台时钟）。
6. **Run 采图与孔板割裂（`internal/runworkspace/recording.go`）**：`ViewPlate`（孔板）和 `ViewGallery`（图库）是两个 tab；`AssetLink` 只有 `{RunID, TaskKey, SampleID}`，缺少 `WellID + Timepoint + FOVIndex`，无法在 12 孔板上直观管理 `162` 张图。
7. **当前三页面视觉与信息层级问题（见 `docs/product/evidence/wave2-*-1360.png`）**：
   - **Design**：主画布大面积空白、卡片只显示 `未填写参数`、步骤顺序/时间线看不出、头部和工具栏多层堆叠；
   - **Run**：顶部元数据堆太多，中间当前步骤浮在空白中且像只读卡片，缺少“1. 看参数 → 2. 计时/做动作 → 3. 勾确认/挂图 → 4. 下一步”的**操作台引导感**；右侧 96 孔板甚至溢出卡片边界，且在不该录读数的接种步骤也默认占着右侧大位；
   - **Notebook**：默认是一张完全空白的白纸，跟 Run 数据视觉断开；`internal/notebook/notebook.go`（只读事件投影）与 `notebook_page.go`（Markdown 编辑器）两套逻辑未真正合流。
8. **Design → Run → Record 统一读模型未收口**：需要确立一个从冻结 Design 蓝图直达 Run 历史与 Notebook 的共用只读投影（`RecordProjection`），让前端“历史审计视图”与“实验本叙事视图”真正渲染同一套数据。
