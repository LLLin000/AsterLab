# AsterLab v1.1 — Structured Recording Contract

- Base: `main@fdaeca9`; RC tag `v0.1.0-rc.1` remains frozen.
- Status: frozen integration contract for v1.1 implementation.
- Non-goal: a second experiment model or a second Run system. Extend existing `runui`, `workflow`, `blocks`, `DesignService` and `RunService`.

## Layers

```
Designer: ResultSchema + plate/sample mapping
Run: ResultGrid (editable) + PlateView (read-only spatial)
Save: RunService.SaveReadoutsBatch -> one atomic execution event
Read: RunSnapshot results -> Table/Plate/Analysis projections
Analysis: derived values only; never overwrite raw cells
```

## ResultSchema

A schema is deterministic from the frozen Design plus assay kind. It is data, not UI code.

```go
type CellStatus string // "raw" | "missing" | "invalid"

type ResultColumn struct {
    Key       string   // "od450", "cq"
    Label     string
    Unit      string
    DataType  string   // "number" | "text"
    Required  bool
}

type ResultAxis struct {
    Kind   string   // "well" | "sample" | "gene" | "replicate"
    Labels []string // plate rows/columns or sample/gene labels
}

type ResultSchema struct {
    ID       string // "cck8.plate96.od450.v1"
    Version  int
    AssayID  string
    Title    string
    Layout   string // "plate96" | "sample_gene" | "group_table"
    Rows     ResultAxis
    Columns  ResultAxis
    Fields   []ResultColumn
}
```

- `cck8.plate96.od450.v1`: 8×12, field `od450`, unit `AU`.
- `qpcr.sample_gene.cq.v1`: rows = samples, columns = genes × technical replicates; field `cq`, unit `Cq`.
- Unknown design/timepoint remains `missing`, never `0`.

## Cell references

```go
type ResultCell struct {
    Row       int     // 0-based grid row
    Column    int     // 0-based grid column
    SampleID  string  // from Designer mapping; may be empty
    Group     string
    Replicate int     // 1-based technical replicate; 0 unknown
    Field     string  // schema field key
    Value     *float64
    Status    CellStatus // empty pointer + missing = no value
}
```

- `Value == nil && Status == "missing"` means explicit missing.
- `Status == "invalid"` preserves the raw text in `Raw` if a future schema needs it; v1.1 may reject before storage.
- Blank clipboard cells are never coerced to `0`.

## Batch API

Add to `RunService`:

```go
type BatchReadoutInput struct {
    RunID       string       `json:"runId"`
    OperationID string       `json:"operationId"`
    TaskKey     string       `json:"taskKey"`
    AssayID     string       `json:"assayId"`
    Timepoint   string       `json:"timepoint"`
    ProtocolStepPath  string `json:"protocolStepPath"`
    ProtocolVersionID string `json:"protocolVersionId"`
    SchemaID    string       `json:"schemaId"`
    SchemaVersion int        `json:"schemaVersion"`
    PlateID     string       `json:"plateId,omitempty"`
    Cells       []ResultCell `json:"cells"`
}

type BatchReadoutResult struct {
    RunID      string `json:"runId"`
    Revision   uint64 `json:"revision"`
    BatchID    string `json:"batchId"`
    EventID    string `json:"eventId"`
    Accepted   int    `json:"accepted"`
    Rejected   []BatchRejection `json:"rejected"`
}
```

`SaveReadoutsBatch` MUST:

1. Validate schema, run/design version, assay/timepoint, cell range, numeric values.
2. Write ONE execution event in one transaction; no per-cell `SaveReadout`.
3. Reject the whole batch if any cell is invalid; no partial commit.
4. Use existing operation-id idempotency and conflict rules.
5. Return the authoritative run revision and event id.
6. Keep raw cell metadata (row/column/sample/group/replicate/field/status) in the event.

Event extension (additive, optional fields):

- `event_type = "measurement"`
- `batch_id`, `schema_id`, `schema_version`
- each measurement gains `row`, `column`, `group`, `replicate`, `status`, `field`
- existing `sample_id`, `endpoint`, `value`, `unit` remain valid for RC/CLI compatibility.

## Grid/UI

- `internal/resultgrid`: native editable grid, keyboard navigation, selection, TSV/CSV parse, undo/redo, draft, full-width mode.
- `internal/plateview`: read-only spatial plate; click selects cell; never a text input at 18px.
- `internal/tableview`: editable table over the same `ResultGrid` state.
- Toggle keeps the same draft and data; selecting a plate well maps to the table cell.
- Pasting shows a preview and explicit overwrite confirmation; blank ≠ zero.
- Save state: Draft / Saving / Saved / Error; errors preserve draft.
- One batch save only.

## Assays

`internal/assays` maps frozen design to schema and cell metadata:

- CCK-8: groups/wells/timepoints/replicates; OD450.
- RT-qPCR: samples, genes, reference genes, technical replicates; Cq.
- Designer step-parameter editing is in Assays owner scope, not a second editor.

## Analysis

`internal/analysis` computes derived values from a batch/raw cells:

- CCK-8 mean, SD, relative activity; configurable control group.
- qPCR ΔCq, ΔΔCq, fold change = 2^-ΔΔCq; reference gene/calibrator configurable.
- Derived output carries source batch/event id and is never written back as raw.

3. CLI reads same batch raw cells.

5. RT-qPCR Sample×Gene×replicates flow PASS.
