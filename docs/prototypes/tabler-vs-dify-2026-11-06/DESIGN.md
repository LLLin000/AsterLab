# AsterLab 设计稿：Dify Workflow Studio + Linear 原则

状态：高保真静态原型，未修改生产 `web/view.html`。

## 页面结构

- 56px 图标导航，无假项目下拉。
- 56px 顶栏：CCK-8 / 实验设计、Draft、保存状态、预览/运行。
- 顶部 280px 受限 DAG：96px 节点、16px 点阵、1px 连线、底部工具。
- 下方 Step Detail：单一滚动容器；不嵌套滚动。
- 孔板 8/12、Calculator 4/12、Table 12/12；按内容分配宽度。
- Proposal Inbox 收起为“待审 1”入口，不覆盖科研卡片。

## 信息层级

1. 实验名与版本
2. Workflow：当前选中步骤
3. Step Detail 标题：加药处理 + 参数/来源/状态
4. 孔板：完整 96 孔坐标、已选/未选/对照、图例
5. Calculator：公式、输入、单位、结果、来源
6. Table：完整行、单位、状态、未保存
7. Markdown：说明与预览

## Dify 借鉴

- 画布与配置内容是一体化工作流，不是 dashboard 卡片墙。
- 画布保持暗色、低噪声；配置区用同一 surface 体系。
- 节点有清楚的选中态（accent border + soft fill），不是彩色填充。
- 工具条紧凑、浮动、低频。

## Linear 借鉴

- 侧栏退后；内容成为焦点。
- 减少边框层级：主要用间距和背景分层，不用每层都描边。
- 字号：标题 19–22，卡片 14–15，正文 12–13，元数据 10–11。
- 单一 accent；状态用文字+颜色。
- 焦点/选中与 hover 分离。

## 状态

| 状态 | 表现 |
|---|---|
| 选中节点 | accent 边框 + 轻填充 + 外发光 |
| 未保存 | Table 标题右侧“未保存 + 草稿” |
| 未解析 | Calculator 输入框待确认，结果不显示数值 |
| 错误 | 行内错误文字 + 图标，卡片保留 |
| 空数据 | 空态说明 + 一个主要动作 |
| 提案 | 顶栏“待审 1”，打开独立审阅面板 |
