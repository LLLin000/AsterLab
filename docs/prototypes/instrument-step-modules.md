# 仪器与操作步骤模块（设计规格）

状态：研究/设计规格，未实现。用于把“工具”从全局页面改成**实验步骤中的可插拔模块**。

常见实验的步骤目的、对照、失败模式和软件/标准参照见
[协议知识、步骤模型与相关项目](../research/2026-11-05-protocol-knowledge-and-related-projects.md)。

## 0. 先纠正“工具”的含义

本规格中的“工具”不是左侧导航里的工具中心，也不是页面弹出“是否使用某仪器”的询问。

工具与仪器的正确形态是：

- **仪器/操作模块 = 一个步骤类型**。它像“加样”“孵育”“读板”一样插入 Protocol 的某个位置。
- **可插拔**：在步骤列表的“+”处插入，或在当前步骤后插入；只新增该步骤及其参数，不改动其它步骤、组别、样本或时间点。
- **不主动询问**：页面不出现“你要不要用离心机/读板机”的提示。只有用户主动插入步骤时，才在上下文相关的插入菜单里看到可选模块。
- **工具动作内联**：配液计算、孔板预览、运行时间估算属于步骤内的 action，不单独占一个页面。
- **不改变实验设计**：插入仪器步骤不等于增加组别、n、检测或样本；它只表达“这一步怎么做”。

## 1. 对象模型

```text
InstrumentProfile（仪器能力档案）
   ↑ referenced by
ProtocolBlockVersion（步骤模块版本，含参数槽位和约束）
   ↑ referenced by
BlockUse（在设计/Protocol 中的一次插入位置）
   ├─ ParameterBinding（本次参数值）
   └─ ReadinessCheck（仪器/耗材/校准是否满足）
   ↑ frozen by
Run → ExecutionEvent（实际执行值、偏差、观察）
```

- **InstrumentProfile**：描述一类仪器的能力边界（板型、体积、转速、温度、通道、耗材），不是某台机器的实时状态。
- **ProtocolBlockVersion**：可复用步骤内容；仪器模块只是带 `instrument_profile_id` 的步骤块。
- **BlockUse**：某次插入的稳定 ID；同一模块插入两次就是两个使用位置。
- **ParameterBinding**：本次实验的值；改参数不复制步骤块。设计默认值必须标来源；未知保持 `待确认`。
- **Run**：冻结步骤块版本和绑定；实际仪器设置、序列号、校准状态、观察值记录在 Run。

## 2. 模块契约

每个模块至少声明：

| 字段 | 说明 |
|---|---|
| `module_id` / `version` | 稳定标识；不可原地修改 |
| `instrument_class` | 移液、离心、孵育、洗板、读板、成像、qPCR、流式等 |
| `instrument_profile` | 可选的型号能力档案；未知型号时只显示通用参数 |
| `purpose` | 这一步为什么做，产生什么 |
| `stage` | 接种 / 处理 / 洗涤 / 染色 / 裂解 / 分离 / 培养 / 测量 / 成像 / 取样 |
| `inputs` | 样本、容器、板、试剂、文件 |
| `outputs` | 处理后的材料、原始观测、派生数据 |
| `container_fit` | 支持的容器/板型/体积范围 |
| `parameters` | 参数槽：类型、单位、范围、是否必需、来源要求 |
| `constraints` | 容量、兼容性、温度、时间、校准、耗材、生物安全 |
| `controls` | 该步骤/读数依赖的空白、标准、阳性/阴性、未染色等；绑定到 assay |
| `decision_points` | 何时继续/停止/重做；例如汇合度、线性范围、校准失败 |
| `failure_modes` | 气泡、蒸发、堵塞、污染、过载、非特异等；用于执行提示和偏差记录 |
| `readout_meaning` | 原始值、派生值、不能直接推出什么 |
| `preview` | 可确定性计算的内容（体积、板位、运行时间、孔数） |
| `execution_schema` | Run 中要记录的实际字段（设置、序列号、校准、观察） |
| `evidence` | 厂商手册/标准/SOP 链接、版本、检索日期 |
| `unknown_policy` | 哪些缺项可保存草案，哪些阻止当前步骤/执行 |

规则：
- 参数有单位、范围和来源；不把“常用值”写成默认值。
- 型号未知时不得套用某型号的转速/波长/通道；只保留通用字段。
- 仪器模块不得修改组别、n、比较目标或检测时间；它只读取这些上下文。
- 一个步骤最多一个主仪器模块；需要多台仪器时拆成连续步骤（如“离心 → 取上清 → 读板”）。

## 3. 插入交互

Protocol 步骤列表：

```text
CCK-8 · 第 1 版
01 接种细胞            [+ 在此后插入]
02 加入处理液          [+]
03 孵育                [+]
04 加入 CCK-8 试剂     [+]
05 孵育                [+]
06 读取 OD450          [+]
```

点击“+”后，菜单贴着该位置展开，而不是跳到工具页：

```text
01 接种细胞  02 加入处理液  [+]  03 加 CCK-8  04 孵育  05 读板
                             │
                             ├─ 移液 / 稀释
                             ├─ 离心 / 分离
                             ├─ 孵育 / 振荡
                             ├─ 洗板
                             ├─ 读板（吸光度 / 荧光）
                             └─ 成像（明场 / 荧光）
```

- 菜单按当前检测、容器、样本类型过滤；不兼容项不显示或说明原因。
- 不出现“是否使用该仪器”的全局提示；不把工具目录作为主页面。
- 选中模块后在原位展开参数表单；未知项显示“待确认”，保存草案不阻断。
- 插入只新增一个 BlockUse；其它步骤顺序、参数、样本关系不变。
- 删除步骤只删除该 BlockUse；不删除被引用的模块版本或其它使用位置。

内联 action 示例：
- 移液步骤内：“计算稀释”“核对体积/孔数”
- 铺板步骤内：“预览计划孔位”“检查板容量”
- 读板步骤内：“估算运行时间”“检查波长/板型兼容”
- 成像步骤内：“检查物镜/通道/曝光是否齐全”

这些 action 不创建新步骤；只有需要“实际执行某仪器”时才插入模块步骤。

## 4. 模块目录（第一批）

### 4.1 移液 / 液体转移
- **用途**：接种、加处理液、加试剂、换液、洗涤、分样、梯度稀释。
- **关键参数**：移液器类型（单道/多道/重复/自动）、体积范围、吸头、目标容器/孔位、转移次数、混匀、换液/弃液、体积来源。
- **约束**：体积必须在移液器/吸头范围内；多道通道数匹配板列；粘稠/挥发性液体需注明；不得把“体积”当浓度。
- **输出**：处理后的样本/孔位、实际加入体积、耗材批次。
- **内联 action**：稀释计算（母液/目标/终体积）、孔位容量核对、体积单位换算。
- **未知**：移液器型号、吸头、实际体积未记录时保留待确认。

### 4.2 自动液体处理（Opentrons / Hamilton 等）
- **用途**：批量转移、梯度、板复制、重复加样。
- **参数**：仪器型号、移液器/通道、labware、源/目标板、转移体积、mix、tip 策略、运行时间。
- **约束**：labware 与板型匹配；死体积、吸头容量、跨板污染控制；不能从设计组别自动推断实际 labware。
- **输出**：实际转移映射、运行文件、耗材使用。
- **内联 action**：预览转移表、估算吸头数/运行时间、检查孔位冲突。

### 4.3 细胞计数
- **用途**：接种前计数、活力评估、密度校准。
- **参数**：方法（血球计数板/自动计数仪）、样本体积、染色（台盼蓝/SafeCount）、稀释倍数、计数范围、复孔数。
- **约束**：自动计数仪典型样本 10 µL、范围约 1×10⁴–1×10⁷ cells/mL、细胞直径约 4–60 µm；超出范围需稀释/浓缩并记录。
- **输出**：浓度、活力、聚集信息；原始图像/计数文件。
- **内联 action**：稀释到目标浓度、计算接种体积；未知细胞浓度时不生成“精确”接种量。

### 4.4 离心
- **用途**：细胞/沉淀/上清分离、板离心、去气泡、样本澄清。
- **参数**：转子、转速或 RCF、时间、温度、加速/减速档、容器/板适配器、配平。
- **约束**：RCF 依赖转子和适配器，不能只填 rpm；板离心需板适配器与密封；温度范围按型号；配平与最大负载是硬约束。
- **输出**：离心后的样本状态、上清/沉淀去向、实际 RCF/时间/温度。
- **型号档案示例**：Eppendorf 5424 R：24×1.5/2.0 mL，100–15,000 rpm，最高约 21,130×g，−10–40°C；定时范围按型号/设置确认。
- **内联 action**：rpm↔RCF 换算（按转子）、运行时间估算、检查适配器。

### 4.5 孵育 / 培养 / 振荡
- **用途**：细胞培养、染色孵育、反应孵育、洗涤浸泡。
- **参数**：温度、CO₂、湿度、时间、振荡速度/半径、容器、开盖/密封、时间锚点。
- **约束**：CO₂ 培养需要透气盖/透气膜；板与培养箱适配；时间相对于哪个事件；不能把“过夜”当成确定时长。
- **输出**：孵育后的材料、实际起止时间、偏差。
- **内联 action**：根据时间锚点生成相对日程；检查容器兼容性。

### 4.6 洗板
- **用途**：ELISA/细胞 assay 洗涤、去上清、减少背景。
- **参数**：板型、洗液、每孔体积、循环数、浸泡时间、振荡、吸液高度/速度、残留体积、缓冲液数量。
- **约束**：细胞 assay 需要低流速/侧壁分液；96/384 板与 manifold 匹配；残留体积和堵孔检查。
- **输出**：洗涤记录、实际体积/循环、残留/堵孔偏差。
- **型号档案示例**：BioTek 405 TS：96/384 孔，1–250 循环，25–3000 µL/孔，浸泡最长 60 min，残留 ≤2 µL。
- **内联 action**：估算洗液体积/时间、检查板型与 manifold。

### 4.7 吸光度 / 浊度读板
- **用途**：OD600、CCK-8、ELISA、蛋白/核酸浓度。
- **参数**：波长、带宽、读数模式（终点/动力学/光谱）、板型、孔数、温度、振荡、读板高度、空白/对照孔。
- **约束**：波长范围与板型按型号；吸光度线性范围；板盖高度；空白孔必须明确；不能把“OD 值”自动换算成细胞数/CFU。
- **输出**：原始吸光度、时间序列/光谱、板文件；派生结果另存。
- **型号档案示例**：Multiskan SkyHigh：200–1000 nm，6/48/96/384 孔，终点/动力学/光谱，96 孔单波长约 6 s，温控 ambient+2–45°C。
- **内联 action**：检查波长/板型/空白孔、估算读板时间、预览板布局。

### 4.8 荧光 / 发光读板
- **用途**：荧光强度、发光报告基因、FRET/TR-FRET 等。
- **参数**：激发/发射波长或滤光片、带宽、增益/曝光、读数模式、板型、读板高度、温度、振荡。
- **约束**：型号支持的滤光片/光源；板材质与背景；串扰/补偿；不能把荧光强度直接当浓度。
- **输出**：原始荧光/发光值、增益/滤光片设置、板文件。
- **内联 action**：检查滤光片/染料兼容、估算读板时间、孔位背景检查。

### 4.9 显微成像
- **用途**：活/死染色、划痕、形态、定位、时间序列。
- **参数**：显微镜型号、物镜、成像模式（明场/相差/DIC/荧光）、通道/滤光片、曝光、增益、Z-stack、时间间隔、位置/视野、stage incubator。
- **约束**：物镜工作距离与容器匹配；荧光通道与染料匹配；活细胞需温控/CO₂；视野/位置 ID 必须可追溯到孔；不能把“图像数量”当独立 n。
- **输出**：图像文件、通道/曝光/物镜、位置/时间元数据。
- **型号档案示例**：Leica DMi8：倒置，明场/DIC/相差/荧光，可选 stage incubator、Z-stack、时间序列、多位置。
- **内联 action**：检查物镜/通道/容器、估算采集时间、预览位置列表。

### 4.10 qPCR
- **用途**：基因表达、拷贝数、突变/SNP、病原检测。
- **参数**：仪器/block、反应体积、化学体系（fast/standard）、引物/探针、染料/通道、循环条件、熔解曲线、参考基因、重复、板布局。
- **约束**：block/反应体积匹配；通道数与染料兼容；多靶标需验证；Ct 不等于表达量；缺参考基因/标准曲线时不得输出绝对定量。
- **输出**：扩增曲线、Ct、熔解曲线、板文件、运行条件。
- **型号档案示例**：QuantStudio 5：96 孔 0.1/0.2 mL，6 滤光片/最多 21 组合，典型 10–100 µL（0.2 mL），运行可 <30 min。
- **内联 action**：检查通道/染料、估算运行时间、预览板布局、检查重复/对照。

### 4.11 流式细胞术
- **用途**：免疫表型、细胞周期、凋亡、分选。
- **参数**：仪器/激光、检测器/滤光片、染料面板、补偿、样本流速、采集事件数、阈值、分选门/收集管。
- **约束**：激光/滤光片与染料匹配；补偿与对照；分析型不等于分选型；样本浓度/体积；不能把事件数当细胞数。
- **输出**：FCS 文件、采集设置、门/补偿、分选收集记录。
- **型号档案示例**：BD FACSCanto II：488/633/405 nm 激光，最多 3 激光/8 色配置，样本流速 10–120 µL/min，采集可达 10,000 events/s。
- **内联 action**：检查染料/滤光片、估算采集时间/样本量、预览门控模板。

### 4.12 分光光度 / 微量核酸蛋白
- **用途**：DNA/RNA/蛋白浓度与纯度、标记效率。
- **参数**：仪器、样本体积、波长/全光谱、blank、稀释、检测限。
- **约束**：微量体积与检测限；blank 与样本基质匹配；A260/280 等比值不能单独证明纯度。
- **输出**：浓度、比值、光谱、原始文件。
- **内联 action**：稀释计算、检查体积/检测限。

### 4.13 涡旋 / 加热 / 恒温混匀
- **用途**：重悬、混匀、裂解、变性、酶反应。
- **参数**：温度、转速/振幅、时间、容器/板适配、加热盖。
- **约束**：容器耐温/耐压；板与加热块适配；挥发性/光敏样本；不能把“加热”当灭活验证。
- **输出**：处理后的材料、实际温度/时间。

### 4.14 样本存储 / 冻存 / 交接
- **用途**：暂存、冻存、外送、批次交接。
- **参数**：温度（4/−20/−80/LN₂）、容器、冻存液、降温速率、位置、时长、交接人/时间。
- **约束**：样本类型与温度；冻存/解冻次数；位置追踪；交接不等于检测完成。
- **输出**：存储位置、温度/时长、交接事件。

### 4.15 非仪器操作步骤
- 洗涤/吸液、固定、透化、封闭、染色、裂解、取样、分样、弃液、封板、标记。
- 这些同样是 ProtocolBlock，只是没有主仪器；参数是体积、时间、温度、容器、样本去向。
- 不因为“没有仪器”就省略步骤；它们经常决定样本去向和时间点。

## 5. 示例：CCK-8 的步骤插入

```text
01 接种 L929（移液模块：体积/孔数/细胞浓度）
02 孵育（培养箱：37°C/5% CO2/时间）
03 加入处理液（移液 + 稀释计算）
04 孵育（培养箱：时间锚点=处理开始）
05 加入 CCK-8 试剂（移液：体积/避光）
06 孵育（培养箱/避光：时长待确认）
07 读取 OD450（读板模块：波长/板型/空白孔/振荡）
08 分析（派生结果，不属于仪器步骤）
```

- 第 07 步是插入的仪器模块；它只引用第 05/06 步产生的板，不改变组别或时间点。
- 空白孔来自设计中的对照关系；读板模块不能自动推断。
- 若 Protocol 型号未知，只显示通用参数，不填 450 nm/6 s 等具体值。

## 6. 示例：活死染色与划痕

```text
活死：
01 接种 → 02 处理 → 03 孵育 → 04 染色（移液/避光）→ 05 成像（显微镜：通道/物镜/曝光）→ 06 分析

划痕：
01 接种 → 02 孵育 → 03 划痕（工具/器械步骤）→ 04 洗涤（洗板/移液）→ 05 0 h 成像 → 06 孵育 → 07 12/24 h 成像（同一视野 ID）
```

- 成像模块必须保留位置/视野 ID；没有配对 ID 时不能声称同视野追踪。
- 每个时间点若使用独立板/孔，样本分配和板记录在执行层分开；仪器步骤不生成样本。

## 7. 型号能力档案（InstrumentProfile）

第一批档案只需覆盖当前真实案例会用到的能力，不追求全品牌：

| 档案 | 关键能力 | 用途 |
|---|---|---|
| `plate_reader.absorbance.multiskan_skyhigh` | 200–1000 nm；6/48/96/384；终点/动力学/光谱；ambient+2–45°C | CCK-8、OD600、ELISA |
| `centrifuge.eppendorf_5424r` | 100–15,000 rpm；最高 21,130×g；−10–40°C；24×1.5/2.0 mL | 细胞/上清/板离心 |

## 8. 与 Run 的关系

- 设计阶段：模块、参数绑定、来源、未知项。
- 创建 Run：冻结模块版本与参数；检查仪器档案/校准/耗材是否满足；不满足只阻断依赖该步骤的操作。
- 执行：记录实际仪器、序列号、设置、时间、操作者、原始文件、偏差。
- 结果：原始观测与派生结果分开；仪器文件/图像/板文件可追溯。
- 设计中的仪器默认值不等于实际执行值；不能把模板参数写成 Run 事实。

## 9. 不做

- 不做全局“工具中心”让用户先选仪器再找实验。
- 不做“是否使用某仪器”的弹窗/向导。
- 不把仪器模块做成实验设计的主对象；设计仍以研究问题、组别、检测、样本关系为中心。
- 不为未知型号编造转速、波长、通道或体积范围。
- 不把仪器模块插入自动改变组别、n、时间点或样本分配。
- 不在设计阶段生成实际仪器事件或完成状态。

## 10. 验收

- 能在 Protocol 任意步骤后插入/删除仪器模块；其它步骤参数和样本关系不变。
- 插入菜单按上下文过滤；不兼容模块不显示或说明原因。
- 每个模块有完整参数、单位、约束、未知状态和 Run 记录字段。
- 读板/成像/离心/qPCR/流式等模块不把仪器输出自动解释成科学结论。
- 同一模块插入两次是两个独立 BlockUse；改一次参数不影响另一处。
- 型号未知时只显示通用字段；不套用具体型号规格。
- 计划/实际分开：设计参数、Run 实际设置、原始文件、派生结果各自可追溯。
