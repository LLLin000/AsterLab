# Start AsterLab

1. Keep the extracted folder together.
2. Double-click `START_HERE.bat`.
3. If the browser does not open, visit `http://127.0.0.1:8832`.
4. The first start creates the database under `%LOCALAPPDATA%\AsterLab`.
5. Close the AsterLab console window to stop the local service.

If port 8832 is occupied, set `LABWORKBENCH_PORT` before starting.
