# RDO-01 readout@1 spec 冒烟（Rust CLI 读取同一 modules.json）

输入 fixture 与本文同目录：`readout-doc.asterlab`、`readout-doc-invalid-kind.asterlab`。

## 合法 readout 文档
$ python3 -c 'import json;print(json.dumps({"source": open("docs/release/evidence/RDO-01/readout-doc.asterlab").read()}))' > /tmp/readout-doc.asterlab.json
$ cargo run -q --bin labworkbench -- asterdoc.validate --input /tmp/readout-doc.asterlab.json

{
  "ok": true,
  "result": {
    "compiled": false,
    "error": {
      "code": "INVALID_INPUT",
      "message": "a design document needs exactly one experiment module"
    },
    "valid": true
  },
  "tool": "asterdoc.validate"
}
[exit 0]

## 非法 value_kind
