## Navigation / shell

- One 48px title/command bar for project, page, global actions.
- A single primary rail for Project / Design / Protocol / Run / Tools; no duplicate page labels in sidebar.
- Project context is real: project list, recent designs/runs, continue-work; no hardcoded `L929` or default run ID.
- Context sidebar only where it adds value (project tree, page sections); collapsible.
- 900×600: rail remains 56px; context panel collapses; content scrolls.
- All actions have empty/loading/error/saving/saved states.

## Page IA

### Project
Project tree, recent designs/runs, continue-last-work, create design/import; no KPI cards.

### Designer
Upper 55–65% workflow canvas: nodes = materials/steps/devices, arrows = dependencies, pan/zoom, select/move/connect/undo. Lower inspector: selected step, parameters, component bindings, plate/well assignment. Visual mapping replaces comma-separated CSV strings. Save/reopen/CreateRun use real Core.

### Protocol
Readable step document: step navigation, purpose, parameters+units, materials/reagents/instruments, checks, expected outputs, design/version links. No second protocol model; editing only where Core supports it.

### Run
Keep validated ~50/50 layout and 96-cell batch path. Plate/Table/Full-width; row/column focus, paste preview, missing/invalid distinct, save states, raw vs derived separation. Do not regress SaveBatch/revision/idempotency.

### Tools & Components
Actionable workspace: 96-well plate layout, dilution calculator, parameter table, component library, structured import. Results can enter Designer or create drafts; no isolated toys.
